# Лабораторна робота №5. ООП у PHP

## Файли
- `AccountInterface.php` — інтерфейс рахунку.
- `BankAccount.php` — базовий клас, баланс, валюта, перевірки та винятки.
- `SavingsAccount.php` — накопичувальний рахунок зі статичною ставкою.
- `index.php` — клієнтський код і HTML-сторінка результатів.
- `style.css` — адаптивна стилізація сторінки.

## Запуск у VS Code
1. Встановити PHP або використати XAMPP/OpenServer.
2. У папці проєкту виконати `php -S localhost:8000`.
3. Відкрити `http://localhost:8000` у браузері.
